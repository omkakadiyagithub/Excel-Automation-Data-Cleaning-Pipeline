# Excel Automation & Data Cleaning Pipeline

## Overview

A Python-based automation pipeline that cleans, processes, and transforms large Excel datasets into business-ready reports.

## Features

- Duplicate removal
- Missing value handling
- Cancelled invoice removal
- Negative value filtering
- Automated KPI generation
- Data quality reporting
- Automated Excel report creation
- End-to-end pipeline execution

## Technologies Used

- Python
- Pandas
- NumPy
- OpenPyXL

## Project Structure

data/
reports/
screenshots/
scripts/

## KPIs Generated

- Total Revenue
- Total Orders
- Total Customers
- Average Order Value
- Top Revenue Country

## How to Run

pip install -r requirements.txt

python main.py
